Google Merchant feed (products.xml)
What to do with this
1. Klik op Download hieronder — je krijgt products.xml.
2. Upload dat bestand naar GitHub → shirtsociete-web (repo root), commit.
3. Het staat dan live op https://shirtsociete.com/products.xml.
4. Merchant Center → Producten toevoegen → Producten uit een bestand → Geef een link naar het bestand op → plak die URL.
5. Draai deze knop opnieuw + upload zodra je shirts toevoegt of verkoopt (of laat Merchant elke 24u de URL opnieuw ophalen).
Sitemap.xml
What to do with this
1. Klik op Copy hieronder.
2. Go to GitHub → shirtsociete-web → sitemap.xml → pencil.
3. Select all, paste this over it, commit.
4. Search Console → Sitemaps → resubmit (or wait for Google to crawl).
